# MITS Altair Programming System II for the Altair-Duino

My resources for using the MITS Altair Programming System II on the Altair Duino kit from adwaterandstir.com.
These resources are specific to the Altair Duino and may not be useful on other emulated systems or original hardware.

I'm using the Altair Programming System II for bare-metal (no operating system) assembly language development on the Altair 8800.
This project is a place to collect my notes on how to use the system on the Altair-Duino.
